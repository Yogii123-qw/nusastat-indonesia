NusaStat: Indonesia in Numbers. A national statistics site for Indonesia that runs offline in a web browser on a desktop and on a phone, from its own files. It covers population, economy, health, education and provinces, with hand-rolled SVG charts and real figures from Statistics Indonesia (BPS). Every figure on the site names its source and year.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. The site has no build step and loads no network resource.
